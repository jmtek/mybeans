# CoffeeBeanCellar

个人咖啡豆库存、冲煮记录与消费习惯分析 Android 原生应用。

## 功能

- **我的豆**：记录豆名、烘焙商、豆种、产区、处理法、烘焙度、风味标签、规格和价格；支持豆种/烘焙度/处理法/品牌筛选，以及列表、画廊两种视图。
- **图片管理**：豆子图片区分为「包装」与「豆子外观」；画廊优先展示豆子外观，列表可同时展示两类图片。所有图片均支持点击查看原图。
- **剩多少**：按库存与赏味状态管理各批次；提供过去 7 天至未来 30 天的时间线，提示养豆完成、赏味节点、过期与刚喝完的豆子。
- **喝一杯**：记录器具、粉量、水量、研磨度、水温、时间、评分、备注和 1–3 张冲煮图片；记录按日期、时间双层时间线展示。
- **修正记录**：可修改冲煮记录实际使用的豆子，系统自动返还原豆库存并扣减新豆库存。
- **算一算**：包含近 7 天消耗、冲煮时段、月度购入开销、冲煮方式、烘焙度、豆种、克重价、产区地图、评分与复购候选等统计。
- **注意啦**：聚合养豆完成、赏味尾段、开封过久和低库存提醒。

## 构建

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew :app:assembleDebug
```

APK 输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 发布 APK

每次发布的 debug APK 会归档到 `release/`，命名规范如下：

```text
CoffeeBeanCellar-debug-YYYYMMDD-HHmmss.apk
```
